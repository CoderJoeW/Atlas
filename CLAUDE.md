# Atlas Project Instructions

## Code Style
- Always use explicit imports — never use wildcard imports (e.g., `import com.example.Foo`, not `import com.example.*`)
- No line should exceed 140 characters in length
- Comments are a last resort. Code should be self-explanatory

## Guiding Principles
- `docs/MISSION.md` holds the mission, priority-ordered principles, scope, and goals — check new features and trade-offs against it
